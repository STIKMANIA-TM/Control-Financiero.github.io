# Control Financiero - Adrián

App personal de control financiero con:
- Registro de ingresos/gastos en tiempo real
- 6 pilares financieros (Fijos, Stikmania, Ocio, Inversión, Emergencia, Ahorro)
- Análisis de porcentajes y rentabilidad
- PWA instalable
- Sincronización multi-dispositivo vía Firebase

## Deploy
GitHub Pages + Firebase (Auth + Firestore)

## Configuración
1. Reemplaza `firebaseConfig` en `index.html` con tus datos de Firebase
2. Sube a GitHub y activa Pages
3. Agrega el dominio en Firebase Auth → Authorized domains
4. Aplica reglas de Firestore
